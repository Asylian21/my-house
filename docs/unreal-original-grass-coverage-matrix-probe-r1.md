# Original grass coverage raw-matrix probe

The R20 replacement gives thinner curved blades but visibly reduces apparent
cover. Its frozen64-root trial remains preserved. This new probe reads original
R16 data from four exact LawnTuft groups:2230+2190+2288+2241=8949 original members.
The native decomposed ordered transforms must equal the actual immutable donor
before-file and original R16 group hashes.

It records every native PerInstanceSMData FMatrix coordinate as binary64, plus
custom-data values and instancing seed controls. A separate transient test copies
the original wrapped rows, then reconstructs rows using the actual native matrix
and plane wrapper types. It avoids u.Matrix/u.Plane aliases that could narrow
precision. Both routes must retain every matrix bit and the original recovered
Transform to be considered ready for a later restoration.

All setter experiments use newly allocated, unowned, meshless transient HISM
objects. No actor is spawned, no component is registered, and no original actor,
component, asset, map, Config/Source/Binaries file is edited or saved. The full
original5306 actor witness and3975 Content/132 protected files are compared
before and after. A reconstruction API failure is recorded explicitly and does
not become restoration acceptance.

Root alone launches the frozen script on original R16 with
`BREZI_REALISM_GRASS_COVERAGE_PROBE_PLAN`, its SHA in
`BREZI_REALISM_GRASS_COVERAGE_PROBE_PLAN_SHA256`, and its exact own output in
`BREZI_REALISM_GRASS_COVERAGE_PROBE_OUTPUT`. Process stem:
`original-grass-raw-matrix-probe-r1`. No restoration is applied. The eventual
fresh combined candidate must retain R19 culls18000/24000cm, restore original
membership, and retire only the three replacement actors; it must preserve the
frozen R22c trial and all unrelated scene fields.
